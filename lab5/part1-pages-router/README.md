# Part 1 — Pages Router blog

Learning implementation based on the official [Pages Router course](https://nextjs.org/learn/pages-router). Uses original short learning posts, not the tutorial's article text.

Node.js 22:
```sh
npm install
npm run dev
npm run build
```

Routes: /, /posts/static-generation, /posts/dynamic-routing, /server-time, /api/hello.

Topics: file-based navigation, next/link, next/image, next/head, CSS modules, global styling, Markdown front matter, getStaticProps, getStaticPaths, getServerSideProps and API routes. Production compilation and browser checks still need to be verified. This repository does not claim completion of the interactive lessons.
